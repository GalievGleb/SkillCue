# SkillCue — подготовка и live-подсказки для собеседований

**[⬇️ Скачать для Windows (последняя версия)](https://github.com/GalievGleb/ScillCue/releases/latest)**

SkillCue ведёт от текста вакансии до уверенного ответа на интервью:

- **Разбор вакансии** — вероятные вопросы, риски и слабые темы по конкретной позиции
- **Тренировка** — отвечаешь на вопросы и видишь, где не хватает конкретики или примера
- **Карта готовности** — процент готовности по темам: что повторить в первую очередь
- **Live-подсказки** — во время созвона компактный overlay показывает короткую подсказку по твоему же опыту

**Бесплатный старт без карты:** разбор вакансии, карта готовности и 15 минут live-подсказок — сразу после установки.

## Установка

1. Скачай `SkillCue-Setup-*.exe` из [Releases](https://github.com/GalievGleb/ScillCue/releases/latest).
2. Запусти установщик. Если Windows SmartScreen покажет предупреждение — нажми
   **«Подробнее» → «Выполнить в любом случае»**. Мы небольшой продукт, сертификат подписи
   кода в процессе получения; сам установщик собран из исходников автора.
3. Открой SkillCue и вставь текст вакансии — через 2 минуты увидишь вероятные вопросы.

Требования: Windows 10/11, 8+ ГБ ОЗУ, интернет для ИИ-ответов.

## Приватность

Распознавание речи работает **локально** (Whisper на твоём компьютере) — аудио никуда не
загружается. Документы и история хранятся на твоей машине. В облако уходит только текст
вопроса для генерации ответа.

## Поддержка и бесплатный разбор вакансии

Telegram: [@SkillCue_support_bot](https://t.me/SkillCue_support_bot) — пришли текст вакансии,
бесплатно вернём вероятные вопросы и риски (даже без установки приложения).
