# SkillCue

Персональная подготовка к собеседованию по конкретной вакансии.

[Скачать для Windows](https://github.com/GalievGleb/ScillCue/releases/latest) · [Сайт](https://skill-cue.ru/) · [Поддержка](https://t.me/SkillCue_support_bot)

> SkillCue находится на стадии работающего MVP перед публичным запуском. Сейчас проект готовится к первым внешним тестировщикам.

## Что делает SkillCue

SkillCue превращает текст реальной вакансии в понятный процесс подготовки:

- выделяет ключевые навыки и вероятные темы собеседования;
- показывает слабые области и карту готовности;
- проводит пробное собеседование по выбранной роли;
- разбирает конкретику, примеры и доказательства в ответах;
- собирает подготовленные факты и заметки в одном рабочем пространстве.

## Сценарий подготовки

1. Вставьте вакансию и добавьте релевантный опыт.
2. Получите вероятные вопросы и темы, которые стоит повторить.
3. Пройдите пробное собеседование вслух.
4. Улучшите ответы по обратной связи SkillCue.
5. Вернитесь к карте готовности перед реальным интервью.

## Приватность по умолчанию

После окончания реплики аудиофрагмент отправляется в OpenAI напрямую или через шлюз SkillCue для распознавания речи. Вакансии, резюме и история подготовки хранятся локально по умолчанию. Подробнее: [архитектура и границы данных](docs/architecture.md) и [политика конфиденциальности](https://skill-cue.ru/privacy.html).

## Архитектура

SkillCue объединяет Electron-клиент, локальный FastAPI-движок, облачное распознавание речи OpenAI и текстовый путь к языковой модели. Публичная схема намеренно не раскрывает ключи, внутренние промпты и детали защиты.

[Посмотреть публичную архитектуру](docs/architecture.md)

## Ответственное использование

SkillCue помогает подготовиться и яснее сформулировать реальный опыт. Продукт не предназначен для выдумывания квалификации, подмены личности или нарушения правил работодателя. Полные правила: [RESPONSIBLE_USE.md](RESPONSIBLE_USE.md).

## Установка

1. Скачайте `SkillCue-Setup.exe` из [последнего релиза](https://github.com/GalievGleb/ScillCue/releases/latest).
2. Запустите установщик на Windows 10/11.
3. Если Windows SmartScreen показывает неизвестного издателя, проверьте, что файл получен из этого репозитория, затем откройте «Подробнее» и продолжите только если источник совпадает.
4. Вставьте вакансию и начните бесплатный разбор.

Требования: Windows 10/11, 8 ГБ ОЗУ или больше, интернет для распознавания речи и функций языковой модели.

## English summary

SkillCue turns a specific job vacancy into a personalized interview preparation plan, skill-gap map, and vacancy-specific mock interview for Russian-speaking job seekers.

SkillCue is a working pre-launch Windows MVP. Completed speech fragments are sent to OpenAI directly or through the SkillCue gateway for transcription. The commercial source code is private; this repository hosts public product information and release artifacts.
