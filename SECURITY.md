# Security Policy

## Reporting a vulnerability

Send a private report in Telegram to [@SkillCue](https://t.me/SkillCue) with:

- affected SkillCue version;
- Windows version;
- clear reproduction steps;
- expected and observed behavior;
- impact and any safe supporting evidence.

Do not open a public Issue for an unpatched vulnerability. Please allow time for acknowledgement and investigation before public disclosure.

## Protect sensitive information

Never include real API keys, passwords, activation keys, access tokens, payment information, resumes, interview recordings, or personal documents in a report. Replace sensitive values with clearly marked examples.

## Scope

Good-faith reports about the published SkillCue installer, update flow, local application boundary, or public website are welcome. Denial-of-service testing, social engineering, accessing other people's data, and tests that violate provider terms are out of scope.
