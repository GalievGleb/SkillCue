# SkillCue Roadmap

This roadmap describes validation milestones, not promised release dates.

## Current

- Working pre-launch Windows MVP.
- Vacancy analysis, skill-gap mapping, spoken mock interviews, and answer feedback.
- OpenAI speech recognition through direct and managed gateway paths.

## Next

- Recruit 10 external testers.
- Validate installation on real Windows devices.
- Collect structured feedback about preparation relevance and usability.

## Then

- Reach 50 monthly active testers.
- Measure preparation completion, repeat use, latency, and inference cost per completed session.
- Maintain a fixed Russian-language evaluation set for vacancy and answer quality.

## Later

- Reach 100 monthly active testers.
- Add production monitoring, budget controls, and per-user limits.
- Explore another language only after the Russian workflow is stable.
